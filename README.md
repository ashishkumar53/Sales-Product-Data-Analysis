# Sales Product Data Analysis | Tableau Dashboard

## Project Overview

This project presents an interactive **Sales Dashboard** developed using Tableau.

The dashboard provides insights into monthly sales performance, quantity ordered, product pricing, and the relationship between sales and product quantities. It helps explore product-level performance and monthly sales trends.

## Dashboard Preview

![Sales Product Dashboard](Dashboard%201.png)

## Key Dashboard Features

The dashboard includes the following visualizations:

1. **Sales by Order Month:** Tracks monthly sales performance and highlights changes throughout the year.
2. **Quantity Ordered by Month:** Compares the quantity of products ordered each month.
3. **Top 5 and Bottom 5 Products by Average Price:** Compares product prices to identify higher- and lower-priced products.
4. **Sales vs Number of Products:** Visualizes monthly sales alongside the number of products ordered.

## Key Dashboard Observations

- December records the highest displayed monthly sales at approximately $4.61 million.
- October records approximately $3.74 million in sales.
- December has the highest displayed quantity ordered at 28,114.
- April records approximately $3.39 million in sales.
- The product price comparison highlights differences in average prices across products.

## Dataset Description

The dataset is embedded within the packaged Tableau workbook (`Sales_Dashboard.twbx`).

The workbook contains 185,950 records and 10 columns, including:

- Product
- Quantity Ordered
- Price Each
- Order Date
- Sales
- City
- Hour

A separate CSV file is not included in this repository because the dataset is available inside the packaged workbook.
